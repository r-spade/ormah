Process only the nodes newer than a durable change-sequence cursor — turning every full O(n²) scan into a bounded delta that drains the backlog oldest-first.

run_auto_linker (and the shared _find_link_candidates preview) should walk only nodes whose seq exceeds a persisted integer watermark, run the unchanged inner linking logic, and advance the watermark only past fully-resolved nodes. Absent watermark = 0, so the historical backlog drains gradually without missing nodes from reindex, import, or transient LLM failures.

Tech stack: Python 3.11, SQLite, pytest (asyncio_mode=auto), existing engine fixture. Spec: docs/superpowers/specs/2026-06-15-auto-linker-incremental-cursor-design.md (v2).

The architecture ↑

A monotonic nodes.seq integer is bumped at the single content-write site (Builder._index_file_nodes_only), allocated from a durable counter in meta.node_seq_next — never MAX(seq)+1, which is non-monotonic across INSERT OR REPLACE. An integer watermark lives in meta.auto_link_watermark (text; absent ⇒ 0).

Durable counter (crit#1) The next seq is read from meta.node_seq_next and incremented, so it never decreases and is independent of the current rows. Every content (re)write lands the node at the head — reindex, import, and restore all re-enter the delta regardless of frontmatter timestamps. Metadata-only UPDATEs elsewhere never pass through the write site, so they never bump seq.
Poison node A malformed LLM response used to return None, leaving the pair unrecorded — the node could never resolve and the watermark would stall forever behind it. Task 5b classifies invalid output as error (recorded, no edge) so the node resolves, while a genuinely unavailable LLM still returns None and correctly leaves the whole run waiting. See Task 6 for how the two are distinguished.
Stale watermark on rebuild A mass reindex re-allocates seq from the durable counter; a leftover high watermark would hide the entire rebuilt store. Task 7b clears the watermark in full_rebuild — the single point every rebuild path funnels through (startup FTS migration, POST /rebuild, restore).

Task dependency flow ↑

The ten tasks form a dependency lattice rather than a straight line. Config (1) is independent. The data spine is 2 → 3: the schema, migration, and durable counter must exist before the builder can allocate a seq. The two consumers, run_auto_linker (6) and _find_link_candidates (7) — highlighted below — both depend on the watermark helpers (4) and the seq select (5); Task 6 additionally needs the error classification (5b) and the data spine (2/3). The rebuild reset (7b) depends only on the watermark key from 4. Everything converges on the verification gate (8).

_WATERMARK_KEY = "auto_link_watermark"


def _get_watermark(conn) -> int:
    """Return the seq of the last fully-processed node, or 0 if unset."""
    row = conn.execute("SELECT value FROM meta WHERE key = ?", (_WATERMARK_KEY,)).fetchone()
    if row is None:
        return 0
    try:
        return int(row["value"])
    except (ValueError, TypeError):
        return 0


def _set_watermark(engine, seq: int) -> None:
    with engine.db.transaction() as conn:
        conn.execute(
            "INSERT OR REPLACE INTO meta (key, value) VALUES (?, ?)",
            (_WATERMARK_KEY, str(seq)),
        )

def run_auto_linker(engine) -> None:
    """Incrementally link nodes with seq above the watermark; advance only past
    fully-resolved nodes."""
    try:
        from ormah.embeddings.encoder import get_encoder
        from ormah.embeddings.vector_store import VectorStore

        settings = engine.settings
        if not settings.llm_enabled:
            logger.debug("Auto-linker skipped: LLM not enabled")
            return

        encoder = get_encoder(settings)
        vec_store = VectorStore(engine.db)
        conn = engine.db.conn
        threshold = settings.auto_link_similarity_threshold
        cross_space_penalty = settings.auto_link_cross_space_penalty
        max_edges = settings.auto_link_max_edges_per_run

        watermark = _get_watermark(conn)
        nodes = _select_nodes_after(conn, watermark, settings.auto_link_max_nodes_per_run)

        created = 0
        last_complete: int | None = None

        for node in nodes:
            if created >= max_edges:
                break  # batch budget spent; do not advance past this node

            node_resolved = True
            text = f"{node['title'] or ''} {node['content']}".strip()
            if text:
                query_vec = encoder.encode(text)
                similar = vec_store.search(query_vec, limit=6)

                for match in similar:
                    if created >= max_edges:
                        node_resolved = False  # interrupted mid-node
                        break
                    if match["id"] == node["id"]:
                        continue

                    similarity = match["similarity"]
                    other_space = conn.execute(
                        "SELECT space FROM nodes WHERE id = ?", (match["id"],)
                    ).fetchone()
                    if other_space is not None and (node["space"] or "") != (other_space["space"] or ""):
                        similarity -= cross_space_penalty
                    if similarity < threshold:
                        continue

                    pair = tuple(sorted([node["id"], match["id"]]))
                    if conn.execute(
                        "SELECT 1 FROM auto_link_checked WHERE node_a = ? AND node_b = ?", pair
                    ).fetchone():
                        continue
                    if conn.execute(
                        "SELECT 1 FROM edges WHERE (source_id = ? AND target_id = ?) "
                        "OR (source_id = ? AND target_id = ?)",
                        (node["id"], match["id"], match["id"], node["id"]),
                    ).fetchone():
                        continue
                    other = conn.execute(
                        "SELECT title, content, type, space FROM nodes WHERE id = ?",
                        (match["id"],),
                    ).fetchone()
                    if other is None:
                        continue

                    llm_result = _llm_classify_link(settings, node, other)
                    if llm_result is None:
                        # LLM UNAVAILABLE (raw None) — transient. Leave node unresolved so the
                        # watermark does not pass it. Not a poison: if the LLM is down, EVERY node
                        # is unresolved, so the whole run waits — no single node blocks others.
                        node_resolved = False
                        continue
                    relationship = llm_result["relationship"]  # may be 'error' (invalid output)
                    _apply_edge(
                        engine, node["id"], match["id"], relationship,
                        llm_result.get("reason", ""), similarity,
                    )
                    # 'error' (poison content) is recorded in auto_link_checked by _apply_edge
                    # and the node still counts as resolved → watermark advances (council v2 crit#2).
                    if relationship not in ("none", "error"):
                        created += 1

            if not node_resolved:
                break  # crit#1/imp#4: stop; watermark stays at the last fully-resolved node
            last_complete = node["seq"]

        if last_complete is not None:
            _set_watermark(engine, last_complete)
        if created:
            logger.info("Auto-linker created %d edges", created)

    except Exception as e:
        logger.warning("Auto-linker failed: %s", e)
